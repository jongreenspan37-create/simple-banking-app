# Vanilla JS Bank Application

A lightweight, front-end banking simulation built with modern JavaScript. Users can create an account, log in, and manage deposits or withdrawals using a paper-style ledger system.

## ✨ Features
* **Account Creation:** Users can register an account directly in the browser.
* **Secure Session:** Simulated login and logout functionality.
* **Ledger System:** Deposit and withdraw funds with immediate balance updates.
* **Clean UI:** Responsive design optimized for both mobile and desktop views.

## 🛠️ Tech Stack
* **HTML5:** Semantic structural markup.
* **Tailwind CSS:** Modern, utility-first styling.
* **JavaScript (ES6+):** Object-oriented programming using Classes and Modular architecture.

## 🧠 Concepts Demonstrated
* **ES6 Modules:** Separation of concerns by splitting code into specialized, reusable files (e.g., `Account.js`, `UI.js`).
* **Class Objects:** Utilizing Object-Oriented Programming (OOP) to manage user accounts and financial data structures.
* **State Management:** Handling application states dynamically without a database backend.
